# Списки

Список — это набор сайтов или диапазонов IP. Трафик к ним keen-pbr направляет по вашим [правилам маршрутизации]({{< relref "/docs/configuration/route-rules" >}}).

**В веб-интерфейсе:** откройте **Маршрутизация** > **Списки** и нажмите **Добавить список**. Задайте название и источник: **URL**, **Файл на устройстве** или **Домены / IP**. Затем нажмите **Применить** в панели черновика.

В файле конфигурации ключ `lists` — объект, где каждый ключ — имя списка, а значение — его настройки. Имя списка: строчные латинские буквы, цифры и `_`, начинается с буквы, не длиннее 24 символов (`^[a-z][a-z0-9_]*$`).

Чаще всего достаточно простого списка доменов:

```json { filename="config.json" }
{
  "lists": {
    "my_sites": {
      "domains": ["google.com", "youtube.com"]
    }
  }
}
```

## Поля

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `url` | string | нет | URL удалённого файла списка для загрузки и кэширования |
| `domains` | array of string | нет | Домены прямо в конфиге |
| `ip_cidrs` | array of string | нет | IP-адреса и подсети ({{< term "CIDR" >}}) прямо в конфиге |
| `file` | string | нет | Путь к локальному файлу списка |
| `ttl_ms` | integer | нет (по умолчанию: `0`) | Сколько минимум хранить IP-адреса доменов этого списка, в миллисекундах. В веб-интерфейсе: **Время жизни IP-кэша (мс)**. Если не задано или меньше 1000, используется `intercept.min_ttl_ms`. Если {{< term "TTL" >}} в DNS-ответе больше, адрес хранится дольше, но не больше `intercept.max_ttl_ms` |
| `detour` | string | нет | Тег outbound, через который скачивается список по `url`. В веб-интерфейсе: **Делать запросы через Outbound**. Пригодится, если источник списка недоступен напрямую |

Домены записываются одинаково во всех источниках. Запись `google.com` подходит для самого домена и всех его поддоменов; `*.google.com` означает то же самое, префикс `*.` писать не нужно. Некорректные домены в файлах и списках по URL пропускаются, а в `domains` — приводят к ошибке конфигурации.

Списки по URL скачиваются только по HTTP или HTTPS, в том числе с адресов в локальной сети.

Локальный файл должен быть обычным файлом (не символической ссылкой). Размер файла ограничен `daemon.max_file_size_bytes` (по умолчанию 8 МиБ), длина строки — 4096 байтами.

В списке должен быть задан хотя бы один из `url`, `domains`, `ip_cidrs` или `file`.

{{< callout type="warning" >}}
Если в одном списке задано несколько источников, записи из них объединяются. Так делать не рекомендуется, лучше заведите отдельные списки.
{{< /callout >}}

## Формат файла списка

Файл по `url` или `file` содержит одну запись на строку:

- IPv4-адрес: `93.184.216.34`
- IPv4 {{< term "CIDR" >}}: `10.0.0.0/8`
- IPv6-адрес: `2606:2800:220:1:248:1893:25c8:1946`
- IPv6 CIDR: `2001:db8::/32`
- Домен: `example.com` — подходит сам домен и все его поддомены (`*.example.com` писать не нужно, запись понимается так же)
- Комментарии: строки, начинающиеся с `#`, игнорируются
- Пустые строки игнорируются

## Примеры

### Удалённый список по URL {#remote-url-list}

Одного домена часто мало: YouTube, например, отдаёт видео с `googlevideo.com`, а картинки с `ytimg.com`. Удобнее подключить готовый список. Их ведёт проект [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community), список для YouTube — [data/youtube](https://github.com/v2fly/domain-list-community/blob/master/data/youtube). В keen-pbr указывайте ссылку на «сырой» файл (кнопка **Raw** на GitHub), как в примере ниже.

В веб-интерфейсе: **Маршрутизация** > **Списки** > **Добавить список**, источник **URL**.

Некоторые строки в списках v2fly содержат служебные пометки (`full:…`, `… @cn`). keen-pbr такие строки пропускает и пишет об этом предупреждение в журнал; остальные домены работают.

```json { filename="config.json" }
{
  "lists": {
    "youtube": {
      "url": "https://raw.githubusercontent.com/v2fly/domain-list-community/refs/heads/master/data/youtube"
    }
  }
}
```

Загруженные файлы кэшируются в `daemon.cache_dir`. Если URL недоступен при запуске, используется кэшированная копия.

{{< callout type="warning" >}}
Чтобы неизменившийся список не скачивался заново при каждом обновлении, сервер должен поддерживать `If-Modified-Since` или `ETag`.
{{< /callout >}}

### Встроенный список доменов

```json { filename="config.json" }
{
  "lists": {
    "my_domains": {
      "domains": ["example.com", "other.org"]
    }
  }
}
```

Каждая запись подходит для домена и всех его поддоменов.

### Встроенный список IP

```json { filename="config.json" }
{
  "lists": {
    "my_ips": {
      "ip_cidrs": [
        "93.184.216.34",
        "10.0.0.0/8",
        "2606:2800:220:1:248:1893:25c8:1946",
        "2001:db8::/32"
      ]
    }
  }
}
```

### Локальный файл

```json { filename="config.json" }
{
  "lists": {
    "local_list": {
      "file": "/etc/keen-pbr/my-list.txt"
    }
  }
}
```

### Время жизни IP-адресов доменов

Чтобы адреса доменов из списка хранились не меньше суток, задайте `ttl_ms`:

```json { filename="config.json" }
{
  "lists": {
    "my_domains": {
      "domains": ["example.com"],
      "ttl_ms": 86400000
    }
  }
}
```
